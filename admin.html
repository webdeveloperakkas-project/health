How post placement works

Main Home Page

Automatic. The newest published post from every category appears in the homepage main slider. It is not a manual placement option.

Latest / Popular

Choose Latest, Popular, Trending, Favorites, or any combination. Trending is a separate hand-picked homepage section. Favorites is reserved for personal picks and affiliate/product recommendations.

Featured Stories / Editor’s Choice

This is a separate editorial selection. Select its checkbox to add a hand-picked article to the homepage Featured Stories section (maximum 20).

Most Viewed

Automatic ranking by real article views after live view tracking is connected.

All Posts

Published articles only. Manage, edit or remove published content.

SEO & Marketing

Published articles are not added to sitemap.xml automatically. Select posts only after final review.

Post placement Select any combination

Every published post appears in its assigned category only within the placements you select. Latest posts appear in the category Latest feed and the homepage Latest feature. Popular-only posts appear in the category Popular feed and homepage Popular feed, not in the homepage Latest feature. Selecting both shows the post in both feeds. Main Home Page automatically features the newest Latest post from each category. Trending appears only when you select Trending. Most Viewed automatically sorts published posts by views.
